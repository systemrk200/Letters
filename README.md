# 📊 Letters — анализ частоты букв

Кроссплатформенное десктопное приложение на **Avalonia UI**, которое анализирует введённый текст и строит гистограмму частоты встречаемости каждой буквы.

![Скриншот приложения](docs/screenshot.png)

## ✨ Возможности

- Ввод или вставка произвольного текста в многострочное поле
- Подсчёт количества вхождений каждой буквы (регистр не важен)
- Игнорирование цифр, пробелов, знаков препинания и прочих не-буквенных символов
- Сортировка букв по алфавиту
- Наглядная столбчатая диаграмма (Bar Chart) через **ScottPlot**
- Автоматический пересчёт и обновление графика по нажатию кнопки
- Кроссплатформенность: Windows, macOS, Linux

## 🛠️ Технологии

- **C# / .NET**
- **[Avalonia UI](https://avaloniaui.net/)** — кроссплатформенный UI-фреймворк
- **[ScottPlot.Avalonia](https://scottplot.net/)** — построение графиков
- **LINQ** — группировка и подсчёт символов

## 📋 Требования

- [.NET SDK](https://dotnet.microsoft.com/download) версии 6.0 или выше
- (опционально) IDE: Visual Studio 2022, JetBrains Rider или VS Code с расширением C#

## 🚀 Запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/ваш-username/letters.git
cd letters
```

Восстановите зависимости и запустите:

```bash
dotnet restore
dotnet run
```

Либо откройте файл решения (`.sln`) в вашей IDE и нажмите **Run / F5**.

## 🎯 Использование

1. Введите или вставьте текст в поле ввода в верхней части окна.
2. Нажмите кнопку **«Построить гистограмму»**.
3. В нижней части окна появится диаграмма с частотой встречаемости каждой буквы.

Пример:

> «Мама мыла раму»
>
> → **а — 4**, **м — 3**, **ы — 1**, **л — 1**, **р — 1**, **у — 1**

## 🔧 Как это работает

- Текст приводится к нижнему регистру (`ToLower()`).
- Фильтруются только буквы (`char.IsLetter`).
- Символы группируются (`GroupBy`) и сортируются по алфавиту (`OrderBy`).
- Полученные пары «буква → количество» передаются в `ScottPlot` для отрисовки столбчатой диаграммы.
